# JWT
|Tipo de Clave	| Algoritmos JWT Comunes	|Caso de Uso Principal|
------------------------------------------------------------------
|Symmetric Key	|HS256, HS384, HS512	|Sistemas internos, clave secreta compartida.|
|RSA Key|	RS256, PS256 (recomendado)|	APIs públicas, microservicios, clave pública para verificación.|
|EC Key|	ES256, ES384, ES512	|Entornos sensibles al rendimiento, claves más eficientes.|
|OKP	|EdDSA|	Alternativa moderna y eficiente a EC.|
