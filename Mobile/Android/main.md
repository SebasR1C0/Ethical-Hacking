# Resources
Tener el conocimiento de la configuración de la aplicación
- AndroidManifest.xml
- res/values/strings.xml

O tipo de archivos .xml que con apktool d NOMBRE.apk podemos hacer un find / -nmae *.xml

Tener en cuenta que archivos importantes como una base de datos como .db o .sqlite puede contener información importante
