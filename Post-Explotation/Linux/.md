# Tools
[LinPeas](https://github.com/peass-ng/PEASS-ng/tree/master/linPEAS) and [LinEnum](https://github.com/rebootuser/LinEnum)

# User Information
```
whoami
id
hostname
env
cat /etc/shadow
```
# Privileges
```
# Privileges
sudo -l

# Enumeration of application
echo $PATH
cat /etc/shells
```

# System Information
```
# OS system
cat /etc/os-release

# Kernel
uname -a

# Initial Procces
/etc/fstab

# CPU info
lscpu
```

# Network
```
# Internal connection
ip a

# Devices
lsblk
df -h

# DNS connection
arp -a

# Printer status
lpstat
```

# Uncommon attacks
- Application or private information in path Documents, Downloads and Desktop
